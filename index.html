Host on GitHub Pages (Free)

Host your custom 3D Bead Generator online in under 2 minutes.

This application is entirely self-contained in a single HTML file. You can deploy it to GitHub Pages for free without compiling or using complex tools:

1
Create a New GitHub Repository:

Go to github.com/new and create a public repository (e.g. named letter-bead-factory).

2
Upload HTML File:

Save this webpage file as index.html on your computer and upload it to the root of your new repository.

3
Enable GitHub Pages:

Navigate to Settings → Pages in your repository. Under Build and deployment, set Source to Deploy from a branch and select main.

4
Enjoy your Live 3D Web App:

GitHub will publish your app at https://<username>.github.io/letter-bead-factory/ within 60 seconds.
